## Mod Descriptions
### Tweaked Detect Life Enchantment
This mod makes the `Detect Life` enchantment scale faster with soul size.
This means the detection distance will be longer, see below. 

It currently has six different versions;
- 1.5x
- 2.0x
- 3.0x
- 4.0x
- 5.0x
- 10.0x

At 3.0x the maximum distance for a Grand Soul becomes 51ft instead of 20ft.
Why not 60ft? I dunno man, it's Oblivion.

Installation;
